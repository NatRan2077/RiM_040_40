# Changelog прошивки РиМ 040.40

Все значимые изменения в прошивке документируются здесь.

**Формат версии:** MAJOR.MINOR.PATCH+BUILD
- **MAJOR** — изменение схемотехники (несовместимые изменения)
- **MINOR** — изменение функционала (новые возможности)
- **PATCH** — текущая версия
- **BUILD** — номер сборки (исправления ошибок)

---
## [1.1.6+1] - 2026-07-02

### Добавлено
- Разрешена запись атрибута 2 объекта даты выпуска в сервисном режиме.
- Добавлен вывод дополнительных отладочных сообщений в лог в потоке обработки данных.

### Изменено
- В режиме поиска целевого счётчика при обращении по USB сбрасывается таймаут окончания поиска (при активном обмене по USB устройство не отключается).

### Исправлено
- Исправлена логика процедуры включения реле:
  - корректное поведение при пропадании связи;
  - команда не отправляется после таймаута, вместо этого отображается сообщение "НЕТ.ОТВ";
  - добавлено прерывание процедуры отправки команды в потоке `thread_dataRequest` для устранения блокировки.

## [1.1.5+1] - 2026-06-22

### Добавлено
- Добавлена возможность чтения MAC-адреса чипа BLE.
- Отображение номера целевого счётчика в режиме поиска.
- При успешном подключении к счётчику отображается сообщение "ПОДКЛ.".

### Изменено
- Объект с параметрами BLE {0.0.96.61.11.255} теперь доступен для чтения с уровнем доступа USB.
- Ожидание нажатия кнопки при переходе от ввода номера счётчика к вводу пинкода изменено на таймаут 2 секунды.
- Сообщение "НЕТ СВ" заменено на "НЕТ.ОТВ".
- Сообщение "LOWBAT" заменено на "РАЗРЯД".

### Исправлено
- Исправлен алгоритм проверки последнего блока при блочной передаче (теперь любое значение кроме 0 считается признаком последнего блока).
- Исправлено некорректное присвоение значения `numbBlock` при ошибке в данных.
- Исправлены зависания программы в режиме поиска и при плохой связи (удалена функция `hp_sleep()` в потоке BLE).
